# Budget Tracker

A full-stack personal finance application built with Python, FastAPI, and Jinja2 templates, featuring both a Command-Line Interface (CLI) and a responsive web interface.

## Features
- **Dual Interfaces:** 
  - **Web Application ('app.py'):** Interactive dashboard rendered with FastAPI and Jinja2.
  - **CLI Tool ('main.py'):** Terminal-based budget tracking tool with input validation and user-friendly prompts.
- **Full CRUD functionality:** Add and delete income and expense records.
- **Dynamic Summaries:** Real-time calculations of total income, total expenses, and net balance with negative balance alert.
- **Persistent Storage:** Data stored in a JSON file for easy access and modification. ('pathlib' and 'json' modules)
- **Responsive UI:** Custom HTML/CSS templates for a seamless user experience.

## Tech Stack
- **Backend:** Python, FastAPI, Uvicorn
- **Templating Engine:** Jinja2
- **Persistence:** JSON / Pathlib
- **Frontend:** HTML, CSS
